UR-068; TR-056. Source: docs/requirements/proposals/collaboration-completion-after-pull.md and docs/planning/0.4.0-plan.md.

Implement an explicit bounded import using gh for extraction and an Application-owned ingestion use case. Preview selected records and identity matching; import descriptions, paginated comments, agreed metadata/timeline and attribution. Preserve existing UUIDs, local planning fields, content/history and unknown supported fields. Repeat unchanged imports without duplicates; changed remote records become attributed source revisions with visible differences, not silent local status overwrites. Validate full input before transactional writes and recover/retry safely. Keep core commands offline; no credential store or generic sync framework. Use this during 0.4 dogfooding before substantial backlog closeout. Remote-only closure propagation is UR-069/TR-057, target 0.5.
