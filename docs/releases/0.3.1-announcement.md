# Roadmap CLI 0.3.1

Draft announcement for publication after the reviewed tag passes CI, PyPI
publishing, and index-install verification. Version 0.3.1 is currently an
unpublished local candidate.

Roadmap 0.3.1 improves the existing offline planning CLI with safer recovery,
clearer diagnostics and more useful automation output.

- Select a workspace explicitly with `--workspace PATH`, inspect entities as
  JSON, and print only the created ID for scripts.
- Clear nullable fields and edit issue due dates/labels and project
  owner/priority without editing canonical documents manually.
- Get candidate IDs for ambiguous lookups, effective configuration explanations,
  and specific repair-preview commands in health output.
- Preserve canonical data through interrupted writes, projection failures,
  migration retries and scoped backup cleanup. Read-only previews remain
  non-mutating even when combined with consent or lifecycle-override flags.
- Retain literal JSON/CSV values, deterministic sorting and empty export
  schemas, while sending operational diagnostics to stderr.

Python 3.12–3.14 on supported macOS/Linux remains the target. Planning data
continues to live in canonical Markdown/YAML; SQLite remains a rebuildable
projection. The explicit 0.1.1 workspace migration remains supported.

Prefer `--format`, `--yes` and `milestone progress`. Deprecated spellings remain
available with warnings through 0.3 and are scheduled for removal in 0.4.
`--yes` supplies consent; `--force` supplies a lifecycle override where supported.
Health repair requires `--fix-type projection|recovery`; preview it first with
`--dry-run`.
