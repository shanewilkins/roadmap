## Scope and remaining limits

The release retains the supported CLI/data contract, explicit legacy migration,
offline core and disposable projection. It does not add the planned 0.4
requirements domain or retire the deprecated 0.3 spellings. Statement coverage
does not establish every branch/flag combination or power-loss outcome. The
single-maintainer capacity and partial requirement evidence remain explicit;
release completion is not an independent B+ assessment.
